# Análisis de Tiendas - Alura Store Latam
Este proyecto fue desarrollado como parte de un desafío analítico con el objetivo de ayudar al Sr. Juan  a tomar una decisión estratégica: vender una de las tiendas de su cadena Alura Store en América Latina para iniciar un nuevo emprendimiento. Para ello, se realizó un análisis de las ventas por tienda y por categorías principales además del rendimiento operativo (costo de envío) de las cuatro tiendas.

🎯 Objetivos
- Objetivo General
Identificar cuál de las cuatro tiendas de Alura Store es la menos eficiente, basándonos en datos reales, para recomendar al Sr. Juan cuál debería vender.

- Objetivos Específicos
  - Analizar los ingresos totales y compararlos entre tiendas. 
  - Evaluar el volumen y rendimiento de ventas por producto y por tienda.
  - Estudiar las reseñas de los clientes como indicador de satisfacción.
  - Identificar las categorías más vendidas y el promedio de tiempo de envío.
  - Generar visualizaciones para facilitar la toma de decisiones basada en datos.
  - Elaborar una recomendación final clara y argumentada.

🧰 Herramientas y Tecnologías
- Python
- Pandas para carga, manipulación y análisis de datos.
- Matplotlib para visualizaciones.

📌 Lo que se Practica
- Carga y análisis de archivos CSV.
- Limpieza y transformación de datos con Pandas.
- Generación de gráficos interpretativos con Matplotlib.
- Cálculo y comparación de métricas clave: ingresos, reseñas, envíos, ventas.
- Redacción de un informe de recomendación basado en los hallazgos del análisis.

📝 Conclusión
Al final del proyecto, se presenta una recomendación sobre cuál tienda debe ser vendida, fundamentada en un enfoque analítico.

⚠️ Nota
Este proyecto fue realizado como parte de un desafío propuesto por Alura Latam dentro de la Especialización en Ciencia de Datos.
Los datos utilizados no son reales; han sido generados con fines educativos y de práctica analítica.
